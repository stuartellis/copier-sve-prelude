# copier-sve-prelude

A Copier template that provides project tooling for consuming Copier templates.

> This project uses the [Standard README](https://github.com/RichardLitt/standard-readme) format.

## Install

To add this template to a project, run this command:

```shell
pipx run copier copy git@gitlab.com:stuartellis-org/templates/copier-sve-prelude.git .
```

## Usage

To see the available tasks, enter this command:

```shell
task
```
